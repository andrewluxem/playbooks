# Playbooks

Practical playbooks for marketing, CRM, team-building, and leadership tasks. Each one turns a defined problem into steps, templates, and checks, so you can bring a clear first pass to your next review without rebuilding the process from scratch.

Every playbook below is free and readable on the web with no email required. Playbooks available as AI skills also ship a downloadable SKILL.md and supporting templates, which you add to a tested AI assistant and invoke when you need that process again. A skill runs only when invoked and does not fetch remote instructions.
